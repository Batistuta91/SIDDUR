# סידור יומי

סידור שמתעדכן לבד לפי התאריך, השעה והמיקום, בנוסחי ספרד, אשכנז ועדות המזרח.
התפילות, ההנחיות והלוגיקה שקובעת מה אומרים בכל יום לקוחים מהאפליקציה „תפילון+" (גרסה 0.2.21) של אורי הולנדר.

## מה יש בתיקייה

- `index.html` – האתר כולו (עיצוב, לוגיקה, יצירת PDF)
- `data/days.json` – מה אומרים בכל יום בשנים 2026–2036, בארץ ובחו"ל
- `data/texts.json` – כל נוסחי התפילות
- `data/z/*.txt` – זמני היום לכל אחת מ־120 הערים
- `fonts/` – גופנים להכנת קובצי PDF

האתר סטטי לגמרי: אין שרת ואין מסד נתונים.

## העלאה ל־GitHub Pages

1. יוצרים מאגר (repository) חדש ב־GitHub.
2. מעלים אליו את כל התוכן של התיקייה הזו (כולל `data`, `fonts` והקובץ `.nojekyll`), כך ש־`index.html` יהיה בשורש המאגר.
3. במאגר: Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי דקה־שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## הרצה מקומית

הדפדפן לא טוען את קובצי הנתונים כשפותחים את `index.html` ישירות מהדיסק, ולכן צריך שרת קטן:

```
python -m http.server 8000
```

ואז פותחים `http://localhost:8000`.

## חשוב לדעת

- הנתונים מכסים את 2026–2036. כדי להאריך, צריך להריץ שוב את החישוב מתוך האפליקציה.
- אין להסתמך על זמני היום הלכה למעשה.
- „תפילון" מופצת בחינם, אבל זכויות היוצרים שמורות לאורי הולנדר. לפני פרסום פומבי כדאי לקבל את אישורו.
